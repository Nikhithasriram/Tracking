# Peritoneal Dialysis Tracker

A comprehensive mobile application for managing and monitoring peritoneal dialysis treatment, designed to help patients track their daily health metrics and maintain better control of their dialysis regimen.

## article
https://nikhitha-personal-website.vercel.app/blog/building-until-the-system-said-no
## Features

### Core Tracking
- **Weight Monitoring** - Daily weight tracking with trend analysis
- **Dialysis Readings** - Record and monitor dialysis session data
- **Fluid Management** - Track water intake and urine output
- **Visual Analytics** - Interactive graphs and charts for all metrics

### Reports & Export
- **PDF Generation** - Generate comprehensive health reports
- **Historical Data** - View trends over time
- **Share Reports** - Easily share reports with healthcare providers

## Getting Started

1. Download and install the application
2. Set up your profile and target values
3. Start logging your daily readings
4. View graphs and generate reports as needed
